# IMDB Sentiment Transformer

This project uses a transformer-based model built with PyTorch to classify IMDB movie reviews as positive or negative. The workflow includes data loading, preprocessing, custom dataset creation, model training, validation, and final evaluation. The final model achieved 76.83% test accuracy, exceeding the project target of 75%.

## Dataset

The project uses the IMDB movie review dataset, which contains labeled reviews for positive and negative sentiment classification.

## Tools and Technologies

- Python
- PyTorch
- Pandas
- Matplotlib
- BERT tokenizer (`bert-base-uncased`)
- Jupyter Notebook

## Results

- Initial untrained validation accuracy: ~50%
- Final validation accuracy: 77.88%
- Final test accuracy: 76.83%
- Project target exceeded: 75%+ accuracy

- Learned how transformer-based models can be adapted for binary text classification
- Improved understanding of PyTorch training and validation workflows
- Gained experience debugging model training issues
- Strengthened Python skills through data exploration and visualization
